INSTRUCTION TYPES (7 supported):
  - LW (Load Word)
  - SW (Store Word)
  - ADDI (Add Immediate)
  - JAL (Jump and Link)
  - BEQ (Branch If Equal)

  - OBI interface multiplexing by SID field
  - Shared monitor and scoreboard

REQUEST-RESPONSE CORRELATION:
  - Transaction ID (tid) based matching
  - Source ID (sid) based agent identification
  - Virtual interface port mapping
